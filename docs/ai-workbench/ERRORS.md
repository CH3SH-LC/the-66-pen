# 失败即定位，不循环试错

`ai.py error 原错误码` 返回对应动作。完整原始错误出处可用
`knowledge.search kind=error` 查，再 `knowledge.read` 查看源码。
首次失败保留 operation_id、意图、回执、存档前后 SHA 和实际进程身份。

| 类别 | 下一步 |
|---|---|
| 参数/schema | describe 后修输入；尚未派发的调用可重新准备 |
| 重名/多变体 | 返回候选并选精确 ID；不自动取首项 |
| 源码漂移 | 无在途操作后更新登记；运行中 helper 的指纹不可偷换 |
| 存档漂移 | 独立读回变化来源；新建上下文，不改旧哈希 |
| 超时/回执丢失 | 状态未知；保持锁，只读实际结果 |
| 回调超预算 | 保留成功前缀；先保存审计，再缩小余量批次 |
| 场景断开 | 从新只读证据核实目标关卡；确需重进才请用户操作 |
| UAC 取消/审批 502 | 记录原生是否启动；现有弹窗未结束不重发 |
| 截图空白/最小化 | 只判像素通道不可用，不判场景不存在 |
| 截止到期 | 停止新原生操作，不延长原授权 |

不要删除历史锁、终止游戏、重启编辑器、扩大权限或更换操作 ID 来“修复”失败。
同一个报错再出现，没有新证据就不再做相同动作。
本次已结束的蒙德任务的 termination.json 是历史结束证据，不是续做指令。
