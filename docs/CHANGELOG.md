# 更新记录

## 0.2.0 · 2026-10-28

- 增加 `pen.py ai` / `ai.py` 统一入口与精简 MCP：任务路由、全文查询、精确 schema、结构化调用与错误处理。
- 公开版登记 179 个生产命令和 27 个路由入口；固定私人场景命令不作为通用工具发布。
- 公共知识库从当前源码构建，含 2,722 个模板技术条目、929 个节点变体及合同；原始图片、网格和私人场景不分发。
- 增加存档上下文、显式所有权合同、跨存档附件转挂与实体拼接；保存哈希、选中对象、父子关系与世界姿态均保留校验。
- 增加批量创建→保存→独立读回的操作流程，重复请求返回原回执，超时结果不明时保留锁。
- 增加后台窗口截图、具有绝对截止时间的助手管理和配套手册。
- 原 `pen.py` CLI、四个只读 MCP 工具与第三方依赖许可继续保留。

本次验证仅覆盖公开源码构建、离线索引、合同、CLI/MCP 和受控编译。
没有连接游戏，没有验证当前游戏版本的实际保存、重开、试玩或视觉效果。
